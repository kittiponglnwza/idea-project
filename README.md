# Hackathon Ideation Repository

Welcome to our team's repository for hackathon ideation and project documentation.

## 📂 Repository Structure

### 1. [VoiceGuard (กำแพงเสียง AI)](./VoiceGuard) 🛡️ **[Selected Idea]**
Our flagship project. An active-intervention AI system designed to protect the elderly from call-center scams and financial fraud in real-time.
- `voiceguard_executive_summary.md` : The complete master summary (Business, Tech, Legal).
- `voiceguard_pitch_assets.md` : Pitch deck assets, competitor matrix, and technical defense.
- `voice_firewall_details.md` : The original detailed breakdown of the Voice Firewall concept.

### 2. [FamilyLink (ประกันลูกกตัญญู)](./FamilyLink) 👨‍👩‍👧‍👦
Our initial concept focusing on a family-linked insurance model with micro-learning to reduce elderly depression and tech-anxiety.
- `family_link_proposal.md` : Project proposal and features.
- `bmc_familylink.txt` : Business Model Canvas.
